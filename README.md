# Simple XOR mini-project

A simple TypeScript application that calculates the XOR of two bit sequences (`0` and `1`).

When started, the application prompts you in the browser for the length of each array and the value of every bit. If the arrays have different lengths, they are right-aligned and the shorter one is padded with zeros. The result is displayed in the browser console.

## Getting started

Install the dependencies and start the development server:

```bash
npm install
npm run dev
```

Open the address provided by Vite in your browser. To see the result, open the developer tools and check the console.

## Other commands

```bash
npm test       # run the tests
npm run build  # compile TypeScript and create the production build
```
